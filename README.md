# 🚀 Node.js API – Quick Start Template

API de prueba desarrollada en **Node.js**, diseñada como plantilla de inicio rápido para nuevos proyectos.

Este repositorio sirve como referencia base para estructurar, configurar y levantar una API REST de forma rápida, limpia y escalable.

---

## 📌 Características

- Node.js + Express
- Arquitectura modular básica
- Endpoint de prueba
